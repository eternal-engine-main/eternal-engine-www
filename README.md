# Eternal Forge Engine - Official Website

Official website for Eternal Forge Engine - A modular, cross-platform MMO game engine.

## 🚀 Live Site

Visit the live website at: [https://eternal-engine-main.github.io/eternal-engine-www](https://eternal-engine-main.github.io/eternal-engine-www)

## 🛠️ Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Grid, Flexbox, animations
- **Vanilla JavaScript (ES6+)** - All interactivity
- **Three.js** - 3D quantum particle effects
- **No build tools** - Direct file deployment

## 🎨 Features

- Responsive design for all devices
- Quantum-themed visual effects
- User authentication system
- Interactive creation studio
- Gallery showcase
- API integration ready

## 📦 Deployment

This site is deployed using GitHub Pages. Any push to the `main` branch will automatically update the live site.

## 🧑‍💻 Development

To run locally:

1. Clone this repository
2. Open `index.html` in your browser
3. No build process required!
